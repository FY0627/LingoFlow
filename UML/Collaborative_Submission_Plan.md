# LingoFlow 7天协同提交计划 (GitHub 记录优化)

此计划旨在模拟一个真实的开发周期，确保团队 5 名成员在 7 天内都有合理的代码提交记录，且逻辑严密，符合老师的验收标准。

## 团队成员及代码简写
- **fcy (范晨懿)**：架构设计、AI 模型对接、核心阅读业务开发
- **czh (陈子韩)**：后端多端互动流转、纠错审批流开发
- **pt (彭涛)**：前端用户端设计、智能阅读交互开发
- **zz (郑展)**：前端管理端看板设计、审批页面开发
- **hzm (黄子铭)**：多端消息通知系统、权限控制与全栈测试联调

---

## 每日任务分配计划

### Day 1: 项目初始化与基础设施
- **fcy**: 搭建前后端项目骨架，设计并初始化核心数据库表结构（Article, User, Vocabulary）。
- **czh**: 后端基础依赖配置（Maven, MyBatis-Plus, Swagger），编写通用的 Result 返回类。
- **pt**: 前端项目初始化（Vite + Vue 3），配置路由基础和全局样式（index.css）。
- **zz**: 管理端布局组件（Sidebar, Header）开发。
- **hzm**: 数据库连接配置，设计系统消息表结构。

### Day 2: 用户系统与认证权限
- **fcy**: 对接 SiliconFlow AI 模型服务层，实现基础文本改写 API 逻辑。
- **czh**: 实现登录/注册后端接口（Controller -> Service -> Mapper）。
- **pt**: 完成用户端登录页、注册页 UI 与接口对接。
- **zz**: 完成管理端登录页 UI 及其权限判断逻辑。
- **hzm**: 集成 Spring Security 或 JWT，实现基础的 Token 校验与角色权限配置。

### Day 3: 智能阅读核心业务
- **fcy**: 开发核心文章生成与保存逻辑，实现不同难度等级的 AI 适配。
- **czh**: 编写文章历史记录接口，实现后端的分页查询功能。
- **pt**: 开发文章详情阅读页，实现侧边栏导航交互。
- **zz**: 开发管理员侧的文章内容管理看板（列表展示）。
- **hzm**: 实现角色路由守卫（RBAC），确保管理员与用户页面隔离。

### Day 4: 核心生词库与交互
- **fcy**: 开发单词自动提取与 AI 翻译对接逻辑。
- **czh**: 实现生词本的增删改查（CRUD）后端接口。
- **pt**: 完成生词本前端 Grid 布局设计与交互。
- **zz**: 在管理端仪表盘加入基础数据统计组件（Mock 数据）。
- **hzm**: 实现后端消息持久化逻辑（消息存入数据库）。

### Day 5: 纠错反馈系统 (用户端)
- **fcy**: 定义纠错工单 DTO 模型，设计工单流转逻辑。
- **czh**: 开发纠错申请提交接口，处理数据存储流程。
- **pt**: 开发文章阅读页与单词卡的“报错”弹窗及其提交交互。
- **zz**: 开发管理员“纠错工单列表”页面，实现基础列表展示。
- **hzm**: 开发消息中心后端接口（未读计数、标记已读）。

### Day 6: 审批流与多端互动 (核心)
- **fcy**: 开发“采纳建议”后的业务数据自动修正逻辑（更新文章/单词表）。
- **czh**: 开发管理员“采纳”与“驳回”的后端审批流处理逻辑。
- **pt**: 完成用户端“消息中心”UI，实现实时拉取通知。
- **zz**: 完成纠错详情对比弹窗，实现采纳/驳回的操作按钮。
- **hzm**: 联调全栈通知触发：当管理员点击采纳时，自动向用户发送系统消息。

### Day 7: 项目优化与验收准备
- **fcy**: 全局代码重构与文档完善（API 接口文档更新）。
- **czh**: 接口性能优化，增加事务回滚处理。
- **pt**: 前端 UI 微调，添加加载动画与响应式优化。
- **zz**: 管理端数据看板实时化刷新优化。
- **hzm**: 系统集成测试，修复全链路 Bug，确保存储库最终代码整洁。
