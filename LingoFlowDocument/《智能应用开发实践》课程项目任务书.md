### 《智能应用开发实践》课程项目任务书

**一、 项目名称** 

​	基于大语言模型的“i+1”智能分级阅读与学习平台

**二、 项目背景与意义** 

​	在第二语言习得理论中，美国语言学家克拉申提出的“i+1”输入假说指出，学习者只有接触到略高于其现有语言水平（i）的语言输入（i+1）时，才能产生最有效的学习效果。然而，在实际的外语学习（如英语日常阅读、日语N3/N4备考）中，学习者极难找到难度恰好匹配的阅读材料。 本项目旨在结合最新的人工智能大语言模型技术，开发一款智能分级阅读平台。通过 AI 动态重写用户感兴趣的真实语料，降低阅读门槛，并辅以交互式阅读和生词追踪功能，解决传统外语学习中“材料太难读不下去”或“材料太易缺乏提升”的痛点，提升个人学习效率。

**三、 项目目标** 

​	设计并实现一个前后端分离的 Web 应用，用户可以输入任意文本或新闻链接，系统通过调用大模型 API，根据用户设定的目标语言和难度评级，自动对文本进行降级重写。同时，平台需提供便捷的交互式阅读界面和个人生词本管理功能，形成完整的“阅读-查词-复习”学习闭环。

**四、 主要研发内容与功能模块**

1. **智能文本重写模块：** 构建动态 Prompt，对接外部大语言模型。根据用户设定的语言难度级别，将复杂原文本转化为词汇和语法结构均符合“i+1”标准的文章。
2. **交互式阅读体验模块：** 在前端实现流畅的阅读体验，支持文章中英文（或日文）对照，支持划词翻译、即时释义展示。
3. **生词本管理与追踪模块：** 用户在阅读中遇到的生词可一键加入数据库。支持生词列表的增删改查（CRUD），并记录单词来源的上下文例句。
4. **AI 课后检测模块（拓展功能）：** 阅读完成后，系统调用大模型针对当前改写后的文章自动生成 3 道阅读理解测试题，并提供解析反馈。

**五、 技术路线** 本项目采用轻量级的单体架构，注重业务逻辑和 AI 接口调用的稳定性。

- **后端开发：** 采用 **Java** 语言，基于 **Spring Boot** 框架搭建 RESTful API 服务。
- **持久层与数据库：** 采用 **MyBatis Plus** 进行数据访问控制，底层使用 **MySQL** 关系型数据库存储用户信息、文章数据和生词记录。
- **前端开发：** 采用 **Vue 3** 框架构建响应式用户界面，搭配 Element Plus 或类似的 UI 组件库。
- **人工智能接入：** 通过 HTTP 请求对接主流大语言模型（如 DeepSeek、Kimi 或通义千问）的开放 API，完成核心的自然语言处理与重写任务。

**六、 进度安排**

- **第一阶段：需求分析与设计。** 确定系统功能边界，设计 MySQL 数据库表结构，完成原型图构思。
- **第二阶段：后端与 AI 接口开发。** 搭建 Spring Boot 工程，编写核心业务逻辑，重点打磨与大模型交互的 Prompt 提示词工程。
- **第三阶段：前端开发与联调。** 使用 Vue 3 完成交互式阅读界面和生词本页面，与后端接口进行数据联调。
- **第四阶段：测试与优化。** 完成系统整体测试，修复 Bug。

**七、 预期成果**

1. 一套运行稳定、代码规范的完整 Web 系统源码（包含前后端及数据库脚本）。
2. 一份详细的项目开发文档或课程实验报告。
3. 平台能够实际演示将复杂文章改写为指定难度，并顺利完成划词收藏和生词管理的流程。
